## Tasks

1. **Adapter intents** (`modules/work/live/adapter.ts`). Implement on the recovery sidecar:
   - `exportIntent(requestId)`: for an unresolved ledger entry, `{ v: 1, requestId, sentAfterVersion, call }` as plain
     JSON (a deep copy of the recorded `WorkMutationCall`); otherwise null (unknown, settled or retired).
   - `adoptIntent(intent)`: validates everything (`v === 1`; a valid request ID; `sentAfterVersion` a non-negative
     integer; `call` a mutation call that passes the same validation the adapter applies to its own calls, with
     `call.params.requestId === requestId`). It registers the intent as unresolved with `applyAuthorized` false and
     sends nothing. It is idempotent: adopting an identical intent that is already unresolved returns true. It returns
     false when the value is invalid, the request ID is held by a different intent, the ID is settled or retired, or
     `UNRESOLVED_LIMIT` is reached. After adoption, `check` and `apply` behave exactly as for an intent recorded by
     this session, and an ordinary call with that request ID is still never sent.
   Tests: round trip export → new adapter → adopt → check (replayed / not applied) → apply once; every rejection case;
   idempotence; limits; that adoption sends nothing.
2. **Contracts** (`packages/contracts/src/services.ts`), placed directly after `WorkServiceTransport`:
   ```ts
   export const WORK_LOCAL_ROUTES = ['load', 'save'] as const;
   export type WorkLocalRoute = (typeof WORK_LOCAL_ROUTES)[number];
   export interface WorkLocalParams {
     readonly load: Record<string, never>;
     /** `binding` comes from `load`. `expectedRevision` must equal the stored revision (0 when nothing is stored). */
     readonly save: { readonly binding: string; readonly expectedRevision: number; readonly value: JsonValue };
   }
   export interface WorkLocalValues {
     readonly load: { readonly binding: string; readonly revision: number; readonly value: JsonValue | null };
     readonly save: { readonly revision: number };
   }
   export type WorkLocalResult<T> = { readonly ok: true; readonly value: T }
     | { readonly ok: false; readonly kind: 'conflict' | 'invalid' | 'too_large' | 'unavailable' };
   export interface WorkLocalTransport {
     call<R extends WorkLocalRoute>(route: R, params: WorkLocalParams[R]): Promise<WorkLocalResult<WorkLocalValues[R]>>;
   }
   ```
   and `readonly workLocal?: Readonly<WorkLocalTransport>;` in `HqServices` directly after `work`. (`JsonValue` is
   declared later in the file; move nothing else.)
3. **Main storage** (new `apps/desktop/electron/work-local.ts`): `createWorkLocal({ root, endpoint, maxBytes })`
   returning `{ call(route: unknown, params: unknown): Promise<WorkLocalResult<…>> }`.
   - `endpoint` is `() => URL | null` (main passes `() => config.get('work')`). No endpoint: `unavailable`.
   - One document per endpoint origin: `<root>/work-local/<sha256 hex of the origin>.json`; directory created 0700,
     file 0600. On disk: `{ "schema": "hq.work-local/v1", "revision": n, "value": … }`.
   - `binding`: an opaque random token per origin for this main process (for example a UUID kept in a map), never the
     address or its hash. `save` with a binding that is not the current origin's token answers `conflict`, so a
     renderer that loaded one endpoint's document can never write into another's after the address changes.
   - `load`: no file → `{ binding, revision: 0, value: null }`; an unreadable or malformed file → `invalid` (never
     replaced automatically).
   - `save`: closed parameter keys; `value` must be JSON (finite numbers, plain objects and arrays, bounded depth);
     serialized size above `maxBytes` (default 16 MiB) → `too_large`; `expectedRevision` not equal to the stored
     revision → `conflict`; otherwise write a temporary file in the same directory (0600, exclusive create), fsync it,
     rename it over the document, fsync the directory, and answer `{ revision: stored + 1 }`. Serialize all calls per
     document. Errors are sanitized: no path, address or exception text crosses IPC.
   - Tests in `apps/desktop/electron/work-local.test.ts` with directories from `mkdtemp(join(os.tmpdir(), …))`:
     paths per endpoint, modes, revision guard, binding guard across an endpoint change, size cap, malformed params
     and values, corrupt files, unconfigured endpoint, concurrent saves, and that a failed write leaves the previous
     document intact.
